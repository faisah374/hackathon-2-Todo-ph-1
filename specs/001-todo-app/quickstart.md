# Quickstart: In-Memory Console Todo App

## Setup
1. Ensure Python 3.10+ is installed.
2. Clone the repository.
3. No external dependencies are required for core execution.

## Installation for Development
```bash
pip install pytest
```

## Running the App
```bash
python src/app.py
```

## Running Tests
```bash
pytest
```

## Basic Usage
When the application starts, you will see a `todo>` prompt.
1. `add Learn Python`
2. `list`
3. `complete 1`
4. `delete 1`
5. `exit`
